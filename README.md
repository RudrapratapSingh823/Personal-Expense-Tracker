# SpendWise — Personal Expense Tracker

Course: Front_end | Course code: CSN371
Submitted to: Kamta Shukla
University: DIT University, Dehradun

## Run the project
1. Extract the ZIP file.
2. Open the `Personal_Expense_Tracker` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension and click **Go Live**.
4. Add an expense using the form.

No Python, Flask, npm, backend, database, or installation is required.

## Features
- Add, edit and delete expense entries
- Categories: Food, Travel, Shopping, Bills, Education, Health, Entertainment, Other
- Total, current-month, transaction-count and average summaries
- Category doughnut chart drawn with the HTML Canvas API
- Search and category filtering
- CSV export
- Responsive desktop and mobile layout
- Clear all records option

## Important data note
This is a frontend-only demonstration. Expense records are kept in JavaScript memory while the page is open. Refreshing or closing the page clears the current records. The project deliberately does not use Local Storage, cookies, a backend, or a database.

## Project files
- `index.html` — page structure
- `style.css` — visual design and responsive layout
- `script.js` — application logic, validation, chart, filtering, and CSV export
